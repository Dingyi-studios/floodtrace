# v0.4.3 场景可见度与操作修复

## 改动

1. 降雨改为在主视图内保持像素可见度的雨线，密度随当前雨强变化，数量和透明度封顶。模型暂停时雨线继续落下，零雨量与关闭图层时不显示；天气卡片的“查看降雨时段”跳到本情景的雨峰，不为雨后时刻制造降雨。
2. 侧栏重建时按工作空间及页签保存外层和内部列表的滚动位置，并以当前可见对象行作为锚点。选中对象、时间更新和日志刷新不再强制回顶部，布局长度变化时也尽量保留同一行在视野中的位置。
3. 侦察小窗按地图的实际宽高分配空间，图像为工具栏与云台让出高度；窄窗口的工具按钮可换行。EO、水深、风险、色板、变焦及展开按钮在小窗内可操作，展开与还原保留当前模式。
4. 整张底图的源河道与湖泊使用连续水面效果，外围河道增加流动示意；城市模型显示的最外60米渐隐，减少计算框的硬切边。城市核心、地形、镜头预设、观察点与数值结果保持原样。

## 水流覆盖与数据口径

底图为3.4×2.7公里；水动力求解仍为城市1.6×1.6公里。外围使用源河道线与湖泊轮廓，流动方向沿源线顺序，仅作空间衔接示意，不能解释为计算水深或流速。46条长度足够的源河道承担外围动效，全部62条源水道及22个源湖泊仍显示。地图外无延伸，城市内仍由原速度场驱动。

外围动效没有新增水动力采样：域外检查点继续返回无模型结果，风险、人员、容量、库存和投送量不受影响。城市显示边缘的渐隐仅影响图像透明度，不修改水位纹理、原生统计或图表。画面明确标注“城市模型流场 · 外围河道流动示意”，快照的displayContext保留显示范围、模型范围、来源和示意标记。
