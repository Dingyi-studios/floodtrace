# v0.4.4 页面与键盘回归

本轮通过浏览器实际操作先复现问题，再修改并回归。数值场、真实地形、雨量来源和任务数据未改变。

| 发现的问题 | 修改及验证 |
| --- | --- |
| 390px窗口的时间轴超出页面至440px，三图文字拥挤 | 时间控件分行、三图横向滚动，顶部入口整理为三行；320/390/650/800/1024/1440px均无页面横向溢出 |
| 在“水深”按钮上按空格，错误启动回放且未切换模式 | 全局快捷键让出按钮、编辑控件及可编辑区域的按键；实际按空格切换相机和2D时保持暂停 |
| 说明窗口不接管焦点，Esc同时影响后台相机 | 原生dialog、双向Tab边界循环、Esc及关闭按钮恢复触发点；说明关闭保留打开的侦察相机 |
| 对象列表重绘后键盘焦点丢失 | 同一工作空间恢复稳定对象焦点并防止滚动；五个工作空间逐一点击和键盘重选，嵌套列表位置保持 |
| 发布后浏览器沿用启发式缓存的旧入口HTML | 给入口HTML、发布清单和固定数据URL添加no-cache校验；服务器配置备份后通过语法检查并平滑加载，普通刷新实际加载v0.4.4 |
| 回放结束可能落在最后一次80ms界面刷新之前 | 播放器对结束帧完整调用时间更新；实际回放到7200/21600s时，状态、场数据、滑块和读数一致 |

- 31项浏览器定向检查通过：见`validation/v4.4/browser-checks.json`。相机工具栏复查320/390/800/1440px，历史强降雨108mm/h约498条雨线，人员总数360，资源随行、相机全屏还原及情景时间保留正常。
