## 适配关系

- 火场进程、烧毁范围和火行为图表 → 降雨、模拟积水、水深、湿面积和关键事件。
- 无人机EO / IR → 同场景可见光 / 模型水深与风险分析；伪彩与灰阶不表示实测温度。
- 热点记录 → 有时间、坐标和来源的模型水深阈值采样；支持定位，不声称影像识别。
- 飞机投放、载荷及行动日志 → 物资投送、有限库存、返程与补给，实际守恒；不宣称产生水动力措施效果。
- 空中追随、道路跟车和队伍 → 直升机、车辆、舟艇、救援队及共享巡检的随行。
- 风矢量 → 求解水流方向与RK2视觉示踪。

额外保留历史雨量 / 水位证据、模拟绿色安全区 / 红色危险区、群众疏散与巡检。视频仅露出入口、未证实的协作、设备接入或分析后端不作为已复刻能力。原视频与原截图不打包进入公开仓库。
