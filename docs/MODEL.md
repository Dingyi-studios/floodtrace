# v0.2 模型与回放说明

## 地表压力情景

本版基于真实 Bellinge 空间资料，河道水位过程为人为设定，没有已验证重现期或历史灾害复原含义。

| 参数 | 设置 |

| 求解器 | ANUGA 4.1.0 / DE0 |
| 范围 | EPSG:25832，E 583000–584600 / N 6132100–6133700 |
| 垂直基准 | DVR90 |
| 网格 | 10 m 交叉网格、102,400 个三角单元 |
| 地形 | 原生 0.4 m DEM → 4 m 面积平均 → 求解网格 |

## 连续水面与速度场

`urban-fields.bin` 为小端 float32，顺序为 `[61 帧, 40401 节点, 4 分量]`。四分量依次为绝对水位（m DVR90）、地表水深（m）、向东速度（m/s）、向北速度（m/s）。展示网格为 201 × 201 节点、间隔 8 m，行从北到南、列从西到东。

湿邻元局部插值得到展示水位；建筑内部隐藏水面由邻近湿街道补齐。展示插值不保证体积守恒，水量统计使用原生求解单元。水面加 0.018 m 显示偏移，波纹只改变法线，反射为程序化天空近似。

前端使用东 / 南坐标，南向速度 = −北向速度。粒子采用 RK2，检查起点、中点和终点的干湿及建筑遮罩。浅水阈值约 0.12 m，当前速度场以 8× 视觉倍率平流；这不是物质输运或真实漂浮物轨迹。物理时间暂停时，粒子仍可展示该时刻流场。默认预算 1700，随镜头距离使用预算的 35%–100%。

## 证据与局限

已保存 12 项数据核验、4 项平流检查和 19 项浏览器验收记录。数值检查包含非负 / 有限场、水量平衡、独立地形配准、展示插值和遮罩；它们证明相应实现的一致性，不证明模型已率定或历史灾害预测准确。

历史窗口为 2012-06-29 04:30–10:30 UTC。实测 level 和独立 SWMM HYDRAULIC_HEAD 使用各自数据性质，管网水头不是地表水深。该窗口尚无地表积水结果，且雨量展示存在站点混合问题，后续会先按站点修正输入与展示。

原生大型求解输出与本机启动检查保存在本地交付中，没有纳入 Git。完整数值复现依赖原始数据和单独配置的求解环境，ANUGA 与 SWMM 必须使用独立进程。
