原生0.4 m水文调整DEM独立平均为4 m，再进入求解网格。真实建筑轮廓使用有限高度的等效抬高床面，楼层 / 屋顶高度为示意。桥涵、窄巷、门窗、路缘及地下空间未完整解析。

历史试算以源时间为UTC的2012-06-29 04:30–10:30窗口驱动。rg5427（23.60064 mm）保留为对照，未与rg5425混用。源事件文件省略的分钟按干时段处理；分钟体积解释为该时间戳开始的60秒雨量。每个数值时间步都按累计曲线精确积分，而不是在长时间步中抽取单个雨强。

历史水深不是历史实测积水，常河道边界及初始条件是假设；无入渗 / 无排水使它属于敏感性试算，不能称为已验证灾害重建。初始干区新增湿面积包含边界初始调整影响，不能全部解释为降雨单一因果贡献。

## 展示场与视觉时间

两组均采用201×201节点、8 m展示采样。`*-fields.bin`为小端float32，维度为[帧,40401节点,4]，分量依次为水位m DVR90、水深m、向东m/s、向北m/s。行北→南，列西→东。配套ground为float32，building mask为uint8。

湿邻元局部插值得到展示水位，建筑内部隐藏水面由邻近湿街道补齐。展示插值不守恒，体积及面积使用原生单元统计。水面仅加0.018 m显示偏移；波纹只改变法线，反射为程序化天空近似。

水流粒子采用RK2，南向速度为负的北向速度，浅水 / 建筑 / 低速 / 域外遮罩。视觉平流倍率8×，不代表漂浮物。雨滴采用饱和密度映射，最多900条细线、不透明度不超过约0.30；默认55%密度预算。雨势、累计量由物理时间决定，雨滴和波纹相位可在暂停时继续。

## 风险分区

100×100个16 m户外单元，每分钟分档；覆盖当前至未来30分钟，额外含一分钟保守缓冲及输出帧包络：

- 绿色候选安全：整段预测水深<0.08 m、速度<0.25 m/s；90 m内存在可通过干道路连接的集结点。
- 红色模型危险：水深≥0.30 m，或水深>0.05 m且速度≥1 m/s / 深速乘积≥0.15 m²/s。
- 黄色：有水影响、连通不确定或需核查。
- 灰色：建筑室内、无可确认道路通达或模型域外等未评估区域。

阈值是演示规则，不是官方安全标准。源道路拓扑未核验桥面、交通限制和真实现场适宜性；绿色不代表经现场验证的安全承诺。

## 人员、集结点与巡检

18个假设队列，每组20人，共360人，投放于源道路节点。集结点3处，容量分别160、140、140人，位置及容量是假设。路径规划有10分钟水情前视，每段道路按实际预计通过时刻复核；示意步行规则为水深<0.15 m且速度<0.5 m/s，不满足时重规划或受阻待援。

在途人数预留容量，到达后转为占用。待疏散+途中+到达+受阻始终为360；巡检另计6人。轨迹记录道路转角的精确时间，前端纯按物理时间采样，暂停和倒放不会暗中推进。

3队巡检各2人，在整个计算窗口保持干燥的源道路上往返，含边界检查45秒和集结点引导90秒驻留。只有移动队列与相同目标的引导队在模拟中距离≤45 m时记录引导交接，人物以举臂符号表达引导。角色适度放大用于可视识别；没有真实人口、救援或行为校准。

## 复现

浏览器回放使用仓库内冻结数据。完整数值复现依赖原始Bellinge输入和独立数值环境。可配置`FLOODTRACE_DATA_ROOT`及`FLOODTRACE_PYTHON`后运行根目录`reproduce.sh`。两引擎始终使用不同可执行进程。实际依赖版本记录在`numerical-environment.txt`，本机原生库设置不作为跨平台自动安装保证。
