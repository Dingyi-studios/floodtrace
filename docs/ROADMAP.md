# 进度与后续方向

## v0.3 已实现

- 历史雨量按 rg5425 / rg5427 分站整理；地表输入仅采用 rg5425，另一站独立对照。
- 降雨进入 ANUGA 计算；复合雨洪和历史降雨试算都有完整地表水面。
- 随雨强变化并限幅的雨滴、当前雨强及累计量。
- 绿色候选安全、红色模型危险、黄色待核查、灰色未评估分区。
- 示意人口360人、18队列、3个容量受限的预定集结点，动态水情检查与重规划。
- 3队6人巡检：安全道路往返、边界检查、集结点引导；只在实际模拟近距离相遇时记录引导交接。
- 跟看队列、跟看巡检、引导交接快捷定位；物理时间暂停和倒放保持一致。
- 数值数据、人员总量、容量、风险分区和实际浏览器验证。

## 仍未实现

- 率定及历史实测淹水范围验证、更多案例与现场道路 / 桥涵 / 集结点核查。
- 地表—管网双向水量耦合、入渗与排水过程。
- 经验证的人口、个体行为、交通冲突、拥堵模型和真实救援调度。
- 在线任意改地形、实时全城重算、结构破坏或真实漂浮物输运。
- 作者确定原创代码独立许可证。

当前绿色分区、人口、容量和任务均为示意规则，不是官方安全判断或真实事件重建。
