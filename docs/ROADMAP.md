# 后续计划

本文件记录 v0.2 基线之后讨论的方向，以下功能尚未实现。

## 降雨与历史积水

- 修正历史雨量曲线的站点混合问题，按雨量站分别整理、检查单位和时间。
- 加入真实或明确标注的假设降雨源项，重新预计算地表水情。
- 雨滴密度随雨强变化，限制屏幕数量与不透明度，暴雨高峰仍保持道路、建筑和人员可读。
- 显示 mm/h、累计雨量和当前使用的站点 / 情景。
- 为历史降雨窗口补算地表积水；明确区分实测记录与模拟水深。
- 无地表结果时显示缺少结果的状态，避免被理解为没有积水。

## 疏散与安全界面

- 绿色候选安全区、红色危险区、黄色待核查区、灰色无模型结果区。
- 分区同时考虑水深、速度、道路连通性和整个疏散时间窗口。
- 预定集结点、容量、道路分组疏散、人员流向和拥堵表达。
- 道路受淹后重新寻路；没有可达路线时显示受阻 / 等待援助。
- 待疏散、途中、到达和受阻人数保持总量一致。

## 巡检与引导

- 示意巡检人员沿安全区道路、边界检查点和集结点往返。
- 巡查、检查、引导群众和返回等任务状态与日志。
- 人员、巡检和业务量随模拟时间推进，暂停时停止。

## 工程整理

- 将本机求解路径改为可配置的数据根目录和运行环境。
- 区分前端回放依赖与完整数值复现依赖。
- 由项目作者确定原创代码许可证。
