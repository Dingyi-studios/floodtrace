# 进度与后续方向

## v0.4 已实现

- 五个统一工作空间：灾情推演、监测证据、无人机、应急处置、疏散与安全。
- 六架模拟无人机、轨迹与遥测、同场景画中画 / 全屏相机、云台 / 变焦、水深与风险分析、两种色板及记录定位。
- 十三个资源及随行观察；源路网车辆检查、模型水域舟艇、共享巡检身份与任务。
- 装载、投送、返程、补给、有限库存及受阻停驶，图表 / 场景 / 日志 / 导出联动。
- 26段参考流程导览，按需加载水场、共用渲染器及错误恢复。
- 逐段截图、跨工作空间组合、物资守恒、独立导航水情验证及浏览器回归；详见版本验收记录。

## v0.3 保留

- 分站历史雨量；两组实际ANUGA雨洪场、连续积水、限幅雨滴、楼层 / 屋顶淹没、水流示踪。
- 绿 / 红 / 黄 / 灰风险分区、360名示意群众、18队列、3处容量受限集结点、沿路水情检查与重规划。
- 3队6人巡检往返、检查与集结引导；按实际模拟近距离相遇记录交接。
- 真实空间资料、历史监测及独立SWMM、水量与人员守恒、暂停 / 倒拖一致。

## 仍未实现

- 历史实测淹水验证、率定、更多案例及现场道路 / 桥涵 / 航道 / 集结点核查。
- 地表—管网双向耦合、入渗与排水过程、措施影响的实际重算。
- 真实无人机 / 相机 / 遥测接入、真实调度、影像识别与热成像测温。
- 经验证的人口、拥堵、交通冲突和个体行为模型；真实飞行性能与续航验证。
- 任意改地形、实时全城重算、结构破坏或真实漂浮物输运。
- 作者确定原创代码独立许可证。

绿色候选区、人员、资源、遥测和任务均有示意假设，不能作为官方安全或救援结论。真实平缓Bellinge地貌保留；不复制参考视频中的火灾区域或未证实后端能力。
