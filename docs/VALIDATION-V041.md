# v0.4.1 应急随行与集结点备注

应急资源此前只在选中时定位，播放时镜头没有持续更新；地图又同时绘制资源与集结点标签，同址对象会逐行向上挤。此补丁改为选中移动资源即进入随行，并将固定信息集中到三个集结点备注。

## 行为与台账

- 应急处置的地图和列表选择都会跟随移动资源，镜头过渡期间也更新目标位置。共用巡检读取疏散场景的同一条轨迹。暂停、倒拖及二维 / 三维切换保留跟随，拖动地图、选择集结点或区域总览退出跟随。
- 任务结束的资源会保持原地；“查看任务进行时”跳到该资源首个移动片段并以0.25×播放。受阻且无可移动片段时明确提示。
- 应急与疏散地图只生成A01、A02、A03标签。标签避让最多上下各一行，无法放下时隐藏，侧栏始终保留集结点入口。
- 固定S01补给设施的模型和列表入口合并进A01备注，数据中的稳定ID与库存事件继续保留。移动资源仍可在地图和资源列表中选择。
- 备注显示已集结群众、在途预留、剩余容量、库存、累计收货 / 出库、累计派出救援队与人员、归属巡检和当前驻点移动资源。图表使用同一模型时间，并包含群众状态变化的精确时刻。
- 库存以任务事件的装载、补给和投送比例更新。事件点及驻点资源以距集结点40 m内的最近点归属；未引入消耗或新增物资。两情景初始库存均为A01 6000箱；末态A01/A02/A03为5440/200/130箱，另有230箱随车或随直升机，合计仍为6000箱。
- 两支救援队共8人均从A01派出，按首次离开时刻累计，巡检另计。360名疏散群众与30名行动人员保持原来的独立口径。以上容量、人员、库存和调度均为模拟示意。

19项真实浏览器检查通过，覆盖直升机、运输车、舟艇、救援队和巡检队的持续随行，暂停与倒拖、二维 / 三维、手动拖动退出、两个情景备注切换、360人 / 3支巡检保留，以及1440×960与540px窄屏。结果见`validation/v4.1/browser-checks.json`，截图保存在SSD的`validation/v4.1/screenshots/`。
