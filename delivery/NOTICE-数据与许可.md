# 数据与第三方许可提示

本交付含 Bellinge 公开数据的派生展示资料和独立求解结果，来源为 DTU / VCS Bellinge 数据集：<https://doi.org/10.11583/DTU.c.5029124>。

- 模型等多数分包为 CC BY 4.0；雨量分包为 CC BY-NC 4.0（研究 / 教育非商业使用）。保留源分包的权利条件，不将整套派生成果统一声明为商业可用。
- 建筑 / 道路等资料的源导出日期为 2019-12-11，不能自动解释为 2012 年资产重建。
- 地形、水位及模型高程使用 DVR90；平面坐标为 EPSG:25832。
- v0.2 地表结果为假设河道高水位压力情景，不是历史灾害重建或已验证重现期；独立 SWMM 模型未经率定；两个引擎没有耦合。旧版设计暴雨结果仅保留为版本资料。
- 建筑轮廓真实；1–3 层、2.9 m 层高、立面与屋顶高度、植被、车辆、应急对象及任务为示意或假设。粒子按求解速度场平流，仅作流场示踪，不代表真实漂浮物。路线未验证桥涵、交通规则和安全通行能力。

前端第三方许可原文位于 `third-party/`（Three.js、Lucide、Vite）。本交付未分发 Python 求解器二进制；其许可和依赖固定于现有独立运行环境。具体来源、场景参数及运行边界见项目根目录的 `README-启动与交付.md`。
